OVERVIEW

這是一套即時 AI 撲克策略顧問，在你打線上撲克時，
自動分析牌局並在螢幕上顯示 GTO 最優策略建議。

核心流程是：看牌 → 識別 → 求解 → 顯示
讓你在每一手牌都能即時參考數學最優解

HUD 特點

  • 永遠置頂（topmost）疊在撲克軟體上方
  • 透明度可調（預設 90%），不遮擋視線
  • 可拖曳移動到任意位置
  • 雙擊縮小成細條，需要時再展開

  • 計算中顯示旋轉動畫，完成即更新
  • 位置選項：左上/右上/左下/右下/自訂座標

手動模式流程

  • 輸入自己的兩張手牌（如 As Kh）
  • 選擇自己和對手的位置
  • 輸入有效籌碼和底池大小
  • 輸入公共牌（翻前留空）
  • 按「分析策略」送出解算
  • HUD 視窗顯示計算中動畫
  • TexasSolver 跑完後，HUD 更新行動建議
  • 同時計算 Equity（勝率）和 EV
自動識別技術
YOLO · OCR · TEMPLATE MATCHING

🤖 YOLO 深度學習識別

  • YOLOv8 模型識別畫面中的卡牌
  • 支援 OBS 虛擬攝影機輸入（--stream 模式）
  • 兩階段偵測：先找桌子位置，再識別卡牌
  • 自動區分英雄手牌和公共牌（依 Y 座標比例）
  • 信心度閾值可調（config.yaml）
  • GPU 加速推論（RTX 支援）

🔤 OCR + 模板匹配

  • OCR 讀取底池金額和籌碼數字
  • 模板匹配辨識卡牌花色和點數
  • 位置偵測：識別 Dealer Button 判斷座位順序
  • 多螢幕支援（monitor_index 設定）
  • 截圖區域可透過 --setup 嚮導設定
  • 每 500ms 自動輪詢（可調）

⚙️ 兩種執行模式

  • TexasSolverRunner：每次求解啟動新進程，用完即退出
  • PersistentSolverRunner：保持 console_solver 進程常駐，每次求解只重用進程，速度更快
  • 非同步執行，不阻塞 HUD UI 介面
  • Timeout 保護（預設 30 秒）
  • 執行緒數設定（Windows 多執行緒有崩潰風險，預設 1）
  • 自動解析 JSON 輸出，轉換為 HUD 顯示格式

設定與初始化
CONFIG.YAML · --setup · REGIONS

📋 config.yaml 主要設定項

  • solver.executable：TexasSolver 執行檔路徑
  • solver.iterations：求解迭代次數（預設 30）
  • solver.bet_sizes：下注尺寸（50, 75, 100%）
  • game.big_blind：大盲注金額
  • hud.position：HUD 位置（topright 等）
  • hud.opacity：透明度（0.0 ~ 1.0）
  • recognition.template_threshold：模板匹配信心值
  • yolo.weights：YOLO 模型路徑
  • regions.*：各截圖區域座標

🔧 初次設定流程

  • 執行 python main.py --setup
  • 設定嚮導引導你框選截圖區域：手牌位置、公牌位置、底池位置等
  • 設定 TexasSolver 執行檔路徑
  • 選擇監視器（多螢幕時）
  • 儲存至 config.yaml
  • 之後直接 python main.py 即可使用
  • current_street_only 優化：決策樹縮小 99%，速度提升 20×
